# Security

[日本語](#日本語) / [English](#english)

## 日本語

脆弱性は公開Issueではなく、[GitHubの非公開報告](https://github.com/RioRio-do/ttemp/security/advisories/new)から連絡してください。
対象は最新リリースと`main`です。秘密情報や個人情報を報告へ含めないでください。

## English

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/RioRio-do/ttemp/security/advisories/new), not a public issue.
The latest release and `main` are supported. Do not include secrets or personal data in a report.
