## 日本語

- 起動時に終了し、メニューバーに表示されない問題を修正しました。
- 画像の取り込み・保存・書き出し中に原本が削除されることがある問題を修正しました。
- 保存データが壊れた場合、元データと復旧用の画像を再起動後も保持するようにしました。
- v0.1.27で起動できない場合は、最新のDMGからApplications内のTtempを置き換えてください。

## English

- Fixed a startup crash that prevented Ttemp from appearing in the menu bar.
- Fixed image originals sometimes being deleted during import, saving, or export.
- Preserve damaged note data and recovery images, including across relaunches.
- If v0.1.27 cannot launch, replace Ttemp in Applications using the latest DMG.
