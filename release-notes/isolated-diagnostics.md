## 日本語

- ローカル検証が本番のメニューバー登録に干渉しないよう、開発・検証用のアプリIDを分離し、本番IDでのローカル診断を禁止しました。
- この変更は、すでにmacOSへ保存された表示設定を修復するものではありません。

## English

- Separated development and test app IDs and blocked local diagnostics with the production ID to prevent tests from affecting production menu-bar registration.
- This change does not repair display settings already saved by macOS.
